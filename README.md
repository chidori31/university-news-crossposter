# University News Crossposter

Панель для кросспостинга новостей в социальные сети.

Проект позволяет создавать публикации в одном интерфейсе, добавлять текст, фото/видео, форматирование, выбирать площадки и публиковать посты сразу или по расписанию.

## Возможности

- Создание публикации через веб-интерфейс
- Поддержка текста, эмодзи, жирного, курсива и ссылок
- Горячие клавиши:
  - `Ctrl + B` — жирный текст
  - `Ctrl + I` — курсив
  - `Ctrl + K` — ссылка
- Загрузка фото и видео
- Live-превью текста и медиа перед публикацией
- Подтверждение перед публикацией
- Публикация сразу
- Отложенная публикация по времени
- Очередь и история публикаций
- Логи успешных публикаций и ошибок
- Редактирование отложенных публикаций
- Удаление отложенных публикаций
- Редактирование медиа в отложенных публикациях
- Отмена запланированных публикаций
- Статусы и ограничения площадок

## Поддерживаемые площадки

| Площадка | Статус |
|---|---|
| Telegram | Работает: текст, фото, видео, альбомы, форматирование |
| VK | Работает текстовая публикация; медиа временно отключены из-за ограничений API/токена |
| MAX | Адаптер подготовлен, ожидается токен бота |

## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/chidori31/university-news-crossposter.git
cd university-news-crossposter
```

### 2. Создать виртуальное окружение

```bash
py -3 -m venv .venv
```

### 3. Активировать виртуальное окружение

Для Git Bash на Windows:

```bash
source .venv/Scripts/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Создать `.env`

Создать файл `.env` в корне проекта и заполнить его по примеру `.env.example`.

Пример:

```env
APP_TIMEZONE=Europe/Moscow

TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=

MAX_BOT_TOKEN=
MAX_CHAT_ID=

VK_ACCESS_TOKEN=
VK_GROUP_ID=
VK_API_VERSION=5.199

DATABASE_URL=sqlite:///./app.db
```

### 6. Запустить проект

```bash
uvicorn app.main:app --reload
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8000/create
```

Очередь и история публикаций:

```text
http://127.0.0.1:8000/scheduled
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `APP_TIMEZONE` | Часовой пояс приложения, например `Europe/Moscow` |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID Telegram-канала/чата |
| `MAX_BOT_TOKEN` | Токен MAX-бота |
| `MAX_CHAT_ID` | ID чата/канала MAX |
| `VK_ACCESS_TOKEN` | Токен VK |
| `VK_GROUP_ID` | Числовой ID сообщества VK без минуса |
| `VK_API_VERSION` | Версия VK API |
| `DATABASE_URL` | Путь к базе данных |

## Безопасность

В репозиторий нельзя добавлять:

- `.env`
- реальные токены
- пароли
- `app.db`
- загруженные пользовательские медиафайлы

Эти файлы исключены через `.gitignore`.

## Назначение проекта

Проект разрабатывается как практический инструмент для автоматизации публикации новостей в социальных сетях, а также как pet-project для портфолио Python/FastAPI-разработчика.

Основной фокус проекта:

- работа с API социальных сетей;
- обработка медиа;
- планировщик задач;
- хранение данных в SQLite;
- веб-интерфейс;
- логирование ошибок;
- практическая автоматизация SMM-процессов.
